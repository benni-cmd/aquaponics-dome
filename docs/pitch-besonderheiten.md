# Besonderheiten-Register: was dieses Projekt und Modell besonders macht (Grundlage fuer den Pitch)

Angelegt 01.11.2026 auf Bens Wunsch (W48): Besonderheiten sollen immer irgendwo vermerkt werden, damit das Projekt und das Modell spaeter gepitcht werden koennen. Gepflegt vom Orchestrator; Sitzungen melden eine Zeile "Besonderheit: ..." in ihrer Kurzmeldung, der Orchestrator traegt sie hier ein.

**Regeln:** (1) Jeder Eintrag nennt den Belegstand ehrlich: belegt (Quelle), gerechnet (Skript, Annahmen) oder Annahme. (2) Was NICHT behauptet werden darf, steht dabei. (3) Kein Ertrags-, Kosten- oder Standortversprechen (D69). (4) Ein Eintrag ist ein Entwurf fuer einen Pitch-Satz, keine Pressemitteilung: erst nachpruefen, dann verwenden.
