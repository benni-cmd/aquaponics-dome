# Loop-Checkpoint (aquaponics-dome)

- **Aktueller Schritt:** Runde 5 fertig, alle Latte-Punkte 1-6 erfuellt, STEP neu exportiert. Schleife beendet.
- **Naechster Schritt:** optional Boolean-Paartest auf Durchdringung; sonst nichts.
- **Latte:** 1-6 erfuellt (6 mit Einschraenkung siehe loop-log)
- **Offene Fehler:** keine bekannten.
- **Bauweise:** `scripts/build.sh <stufe> <runde>` erzeugt `designs/dome.sc` + `renders/round-NN.png` (Skript `scripts/gen_dome.py`, Parameter-Tabelle `P`).
